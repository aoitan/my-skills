# Coding Process

以下の厳格なワークフローに従って、他のスキルを順番に呼び出し、実装プロセスを進行します。

## Workflow:
1. `implement-tdd-flow` スキルに従って実装する
2. 完了後、`checkpoint` に従って作業記録を残す
3. `code-review` に従ってレビュー修正する
   - 重大な指摘があった場合は修正を指示し、再度レビューを行う（最大5回まで）
   - 現在のループ回数を必ず内部でトラッキングすること。
4. レビューが通過した、あるいは5回を超えた場合はループを抜ける
   - 5回を超えた場合は、指摘経緯と残課題をまとめたレポートを出力する
   - 以降の手順はスキップする
5. コミットする
   - ブランチが切られているかチェックする
6. 再度 `checkpoint` に従って作業記録する
7. `pr-ready-code-explainer` スキルに従って実装を解説する
