# 注文一覧のCSVエクスポート仕様

## 実行と対象データ

注文一覧の「CSV出力」から実行する。現在の絞り込み条件に一致する全注文を対象とし、画面のページサイズでは件数を制限しない。

## 権限

管理者だけが利用できる。権限のない利用者からのAPIリクエストには403を返す。

## ファイル形式

- 文字コード：UTF-8 BOM付き。
- 列の順序：注文ID、注文日時、税込金額。
- 注文日時：Asia/TokyoのISO 8601表記。
- 対象が0件の場合：ヘッダー行だけを返す。

## 件数制限と失敗時の動作

対象が10,000件を超える場合はファイルを作成せず、HTTPステータス422と「条件を絞り込んでください」を返す。10,000件ちょうどの場合は出力対象とする。

出力に失敗した場合も、注文データは更新しない。

## 未決事項

10,000件出力時の応答時間目標は未決定。

## 受入条件

- 現在の絞り込みに一致する注文が、画面のページサイズにかかわらず出力される。
- 管理者は出力でき、権限のないAPIリクエストには403が返る。
- 列順、文字コード、注文日時の表記が指定どおりである。
- 0件の場合はヘッダー行だけが返る。
- 10,000件の場合は出力でき、10,001件以上の場合はファイルを作成せず422と指定のメッセージが返る。
- 出力失敗時に注文データが変更されない。
