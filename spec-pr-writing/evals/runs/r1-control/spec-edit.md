# 検索条件の保存

## 対象と保存内容

ログイン中の利用者が検索条件を保存し、保存済みの一覧から再適用できるようにする。保存先はブラウザのlocalStorageとし、検索語と並び順を保存する。

サーバーへの保存と端末間同期は対象外とする。共有端末では、保存した条件がブラウザに残る。

## 保存操作

- 「条件を保存」を押すと、現在の検索語と並び順を指定した保存名で保存する。
- 保存名は1〜40文字、保存件数は最大20件とする。
- 同じ保存名が存在する場合は確認ダイアログを表示し、承認された場合だけ上書きする。取り消した場合は既存データを変更しない。

## エラー

次のいずれかに該当する場合はエラーを表示し、既存データを変更しない。

- 保存名が空である。
- 保存名が41文字以上である。
- すでに20件保存されている状態で、新しい名前の条件を保存しようとした。

## 再適用

保存済み条件の一覧から条件を選び、保存されている検索語と並び順を再適用できる。

## 受入条件

- 保存後にページを再読み込みしても、保存した条件が残っている。
- 同名の条件の上書きを取り消すと、元の条件が保持される。
- 保存名または保存件数の上限を超えた場合、エラーが表示され、既存データは変更されない。
