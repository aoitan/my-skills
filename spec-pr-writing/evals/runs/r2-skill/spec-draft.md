# 注文一覧のCSVエクスポート

注文一覧の「CSV出力」から、現在の絞り込みに一致する全注文を出力する。画面のページサイズでは出力対象を制限しない。

## 権限

管理者だけが利用できる。権限のないAPIリクエストには403を返す。

## 出力形式

- 列は注文ID、注文日時、税込金額の順とする。
- 文字コードはUTF-8 BOM付きとする。
- 注文日時はAsia/TokyoのISO 8601表記とする。

## 件数と失敗時の動作

- 対象が0件の場合は、ヘッダー行だけを返す。
- 対象が10,000件を超える場合は、ファイルを作成せず、422と「条件を絞り込んでください」を返す。
- 出力に失敗しても、注文データは更新しない。

## 未決事項

10,000件時の応答時間目標は未決定。
