# 注文一覧のCSVエクスポート仕様

## 実行方法と権限

管理者が注文一覧の「CSV出力」から実行する。管理者以外は利用できず、権限がないAPIリクエストにはHTTP 403を返す。

## 出力対象

現在の絞り込み条件に一致する全注文を出力する。画面のページサイズによる件数制限は適用しない。

## ファイル形式

- 文字コード：UTF-8 BOM付き
- ヘッダーと列順：注文ID、注文日時、税込金額
- 注文日時：Asia/TokyoのISO 8601表記

## 件数ごとの動作

| 対象件数 | 動作 |
| --- | --- |
| 0件 | ヘッダー行だけのCSVを返す。 |
| 1〜10,000件 | 対象の全注文をCSVで返す。 |
| 10,000件超 | ファイルを作成せず、HTTP 422と「条件を絞り込んでください」を返す。 |

## データの保全

CSV出力に失敗しても、注文データは更新しない。

## 未決事項

10,000件を出力する場合の応答時間目標は未決定。
