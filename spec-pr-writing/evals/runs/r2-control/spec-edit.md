# 検索条件の保存

## 概要

ログイン中の利用者が検索条件をブラウザに保存し、保存済みの一覧から再適用できるようにする。

## 保存する情報

- 保存名：1〜40文字
- 検索条件：検索語、並び順
- 保存先：ブラウザのlocalStorage
- 保存件数の上限：20件

## 保存時の動作

「条件を保存」を押すと、入力された保存名で現在の検索語と並び順を保存する。

同じ保存名の条件がある場合は、確認ダイアログを表示する。利用者が承認した場合だけ上書きし、取り消した場合は元の条件を保持する。

次の場合はエラーを表示し、既存データを変更しない。

- 保存名が空である。
- 保存名が41文字以上である。
- 保存済み条件が20件ある状態で、新しい名前の条件を保存しようとした。

## 再適用と保持

保存済み条件は一覧から選択して再適用できる。保存した条件はページを再読み込みしても保持する。

## 対象外・利用上の注意

サーバーへの保存と端末間同期は対象外とする。共有端末を利用した場合も、保存した条件はそのブラウザに残る。

## 受入条件

- 保存後にページを再読み込みしても、保存済み条件が残る。
- 同名条件の上書きを取り消すと、元の条件が残る。
- 保存名の文字数または保存件数が上限を超えた場合、エラーを表示し、既存データを変更しない。
