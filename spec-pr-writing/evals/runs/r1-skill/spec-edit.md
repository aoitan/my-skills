# 検索条件の保存

ログイン中の利用者が「条件を保存」を押すと、検索語と並び順をブラウザのlocalStorageに保存する。保存済み条件は一覧から再適用できる。

## 保存条件

- 保存名は1〜40文字、保存件数は20件までとする。
- 同じ名前の条件は、確認ダイアログで承認された場合だけ上書きする。取り消した場合は元の条件を保持する。
- 保存名が空、41文字以上、または21件目の新規保存の場合は、エラーを表示し、既存データを変更しない。

## 保存範囲

サーバーへの保存と端末間同期は今回の対象外とする。共有端末ではブラウザに条件が残る。

## 受入条件

- 保存後にページを再読み込みしても条件が残る。
- 上書きを取り消すと元の条件が残る。
- 上限を超える保存では既存データが変わらない。
